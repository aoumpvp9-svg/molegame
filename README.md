# 🐹 MOLE RUSH! — 캐주얼 아케이드 두더지 잡기

신나고 경쾌한 아케이드 감성의 3×3 두더지 잡기 웹게임입니다. 순수 HTML, CSS, JavaScript로 개발되었으며 반응형 모바일 및 PC 환경을 모두 지원합니다.

## 🎮 게임 특징
- **네온 아케이드 비주얼**: 보라색, 민트색, 황금색을 활용한 생동감 넘치는 카드형 UI 및 글래스모피즘
- **다양한 캐릭터**:
  - 🐹 **일반 두더지**: +10점 획득
  - ✨ **황금 두더지**: +30점 대량 획득
  - 💣 **폭탄 두더지**: -15점 감점 & 콤보 초기화
- **콤보 시스템**: 3연속 적중부터 매 성공마다 **+5점 추가 보너스**!
- **스피드 난이도 가속**: 45초 동안 게임이 진행될수록 두더지의 등장 속도와 반응 속도가 점차 빨라집니다.
- **최고 기록 저장**: 브라우저 `localStorage`를 연동하여 최고 점수가 자동 보존됩니다.
- **풍부한 효과음**: 브라우저 내장 Web Audio API를 활용한 경쾌한 8비트 사운드 (상단 음소거 버튼 제공).

## 🛠️ 기술 스택
- **HTML5**: 시맨틱 웹 구조 및 반응형 뷰포트
- **Vanilla CSS**: CSS Grid, Flexbox, Keyframe Animations, Glassmorphism
- **Vanilla JavaScript**: 순수 DOM 조작, Web Audio API, LocalStorage

## 🚀 플레이 방법
1. **[게임 시작]** 버튼 클릭 또는 키보드 **[Space]** 키 누르기
2. 구멍에서 튀어나오는 두더지를 빠르게 클릭하거나 터치
3. 폭탄은 피하고 황금 두더지와 콤보 보너스를 노려 최고 기록 달성!
